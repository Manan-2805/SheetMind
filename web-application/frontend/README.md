# SheetMind Web Frontend

This is the frontend component for the SheetMind web application, built using React, TypeScript, and Vite.

## Prerequisites
- Node.js (v18+)
- npm (Node Package Manager)

## Setup and Installation

1. Navigate to the frontend directory:
   ```powershell
   cd web-application/frontend
   ```
2. Install dependencies:
   ```powershell
   npm install
   ```

## Development Server

To start the development server with Hot Module Replacement (HMR):
```powershell
npm run dev
```

## Build Instructions

To build the frontend for production:
```powershell
npm run build
```

## Technologies Used
- React
- TypeScript
- Vite
- Zustand
- Tailwind CSS
